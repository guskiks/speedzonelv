SPEEDZONE LV — V3 UPDATE

Šeit ir visi faili, kas jāaugšupielādē GitHub, lai iegūtu jaunāko versiju.

1. GitHub repozitorijā izvēlies Add file -> Upload files.
2. Atver šo v3-update mapi un ievelc GitHub logā VISU tās saturu.
3. Nevelc pašu v3-update mapi.
4. Commit directly to main.
5. Atver Actions -> Build unsigned IPA -> Run workflow.
6. Pēc Success lejupielādē SpeedZoneLV-unsigned-ipa un ielādē IPA iLoader.

Faili saglabā pareizo mapju struktūru un aizvietos vecās versijas.
